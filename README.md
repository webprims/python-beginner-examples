# Python Beginner Examples

Beginner-friendly Python examples maintained by **WebPrims** for students who want to learn by writing and running real code.

This repository starts with the basics and gradually moves into practical concepts such as conditions, loops, functions, collections, file handling, exceptions, and object-oriented programming.

## What you'll learn

- Variables and basic data types
- User input and output
- Conditions (`if`, `elif`, `else`)
- `for` and `while` loops
- Functions
- Lists, tuples, sets, and dictionaries
- File handling
- Error handling
- Classes and objects
- Small practice challenges

## How to run an example

Make sure Python 3 is installed.

```bash
python --version
```

Clone the repository:

```bash
git clone https://github.com/webprims/python-beginner-examples.git
cd python-beginner-examples
```

Run any example:

```bash
python 01-basics/hello_world.py
```

## Learning approach

Don't just copy the code. Change values, break things, read the error messages, fix them, and try adding your own features. That is where most of the learning happens.

## Practice path

1. Run each example once.
2. Rewrite it without looking at the original.
3. Modify the example with your own values and conditions.
4. Complete the tasks inside the `exercises` folder.
5. Combine multiple concepts into a small project.
